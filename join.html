Open this page in Firefox on your tablet. Netflity runs in Firefox for Android. Get Firefox

  1. Add Netflity to Firefox

    Netflity is installed.

    Download Netflity

    Then install it in Firefox. You only do this once.

    1. Open the Firefox menu ⋮ → Settings, scroll to the bottom and tap About Firefox.

    2. Tap the Firefox logo 5 times. You'll see “Debug menu enabled”.

    3. Go back to Settings and tap Install extension from file.

    4. Pick netflity.xpi from Downloads, then tap Add.

    Come back to this page afterwards. It will show that Netflity is installed.

  2. Open Netflix

    Open Netflix

    Sign in if Netflix asks. If Firefox offers to open the Netflix app, stay in Firefox.

  3. Join the room

    Netflity opens on the right side of Netflix with the room code already filled in. Type your name and tap Join.
