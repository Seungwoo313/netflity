Netflity

둘이 같이 보는 넷플릭스

각자 자기 넷플릭스로 재생. 재생, 정지, 이동은 자동으로 맞춤. 채팅과 리액션은 화면 오른쪽 사이드바.

가짜 넷플릭스로 체험 설치

체험: 탭 두 개(A, B)를 열고 같은 방 코드로 입장

기능

동기화
재생, 정지, 이동이 1초 안에 반영. 어긋나면 자동 보정.
버퍼링 대기
한쪽이 버퍼링되면 같이 멈췄다가 같이 재생.
사이드바
채팅과 설정. 열면 영상이 옆으로 줄어들고, 접으면 작은 독만 남음.
리액션
이모지가 화면 위로 떠오름. 연타하면 콤보. 숫자키 1–8.
일시정지 이유
간식, 화장실, 전화, 휴식, 잠깐. 상대 화면에 표시.
카운트다운
3초 뒤 두 화면이 동시에 재생.

설치

맥 · 사파리

  1. npm run build:safari
  2. Netflity.app 실행 후 사파리 설정 → 확장 프로그램에서 Netflity 켜기
  3. 넷플릭스에서 작품을 열면 오른쪽에 독 표시

갤럭시 탭 · Firefox

  1. Firefox에서 넷플릭스 로그인, 메뉴에서 데스크톱 사이트 켜기
  2. 설정 → Firefox 정보 → 로고 5번 탭 → 파일에서 확장 설치 → netflity.xpi
  3. 작품을 열고 받은 방 코드로 입장

맥 · 크롬 (개발용)

  1. chrome://extensions → 개발자 모드
  2. 압축해제된 확장 프로그램 로드 → extension/dist/chrome
개인용 프로젝트. 넷플릭스와 관계없음.
